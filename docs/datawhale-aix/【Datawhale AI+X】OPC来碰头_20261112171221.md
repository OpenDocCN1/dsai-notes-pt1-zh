在本节课中，我们将学习OPC（一人公司）的含义，了解Datawhale AI+X系列OPC碰会的背景和初衷，听取三位嘉宾的真实探索故事，掌握如何在AI时代作为个体行动，建立内容工作台，进行项目管理，以及制作人物展览。本节课适合对超级个体、一人公司感兴趣的初学者，不需要任何技术背景，我们会用大白话把每一个概念讲清楚。

## 第一节：直播背景与OPC基本概念🌱

Datawhale AI+X系列推出了OPC碰会活动，这个活动是在吐槽会社区里日常推进的。月亮作为主持人，介绍说社区里有很多活跃的伙伴，自己也是其中一位。今天特别邀请了两位嘉宾，分别是Joice和Mindy。OPC碰会的初衷是想邀请更多在超级个体或OPC成长道路上的伙伴，分享自己阶段性的思考。这里说的阶段性思考，不一定是已经非常成功的经验，也可以是往前走的一小步，或者是正在探索的过程。每个人真诚的探索故事，对其他人来说都可能有启发，值得被更多人看见和发现。

直播采用相对去中心化、更开放的形式。在场的伙伴可以随时开麦，最后会有互动环节，希望听到大家在OPC或超级个体探索道路中真实的困惑、真实的需求，以及正在做的行动。把这些经验沉淀下来，未来能支持更多个体探索者在成长道路上获得相应的帮助。今天的氛围非常真诚，大家虽然在云端见面，但希望还原线下面对面的信任和交流感受。

OPC的核心概念可以用下面的公式来描述：

$$
OPC = One Person Company = 一人公司 / 超级个体
$$

意思是一个人独立运作，承担多个角色，完成过去需要整个团队才能完成的工作。

## 第二节：Joice的分享：从品牌设计师到AI协作者🎨

上一节我们介绍了OPC的基本概念和直播背景，本节我们来看看第一位嘉宾Joice的探索历程。

Joice介绍自己有三个身份。第一个身份是以前在外企品牌部门做市场营销设计的设计师，服务过很多品牌，现在也陆续在做自由职业。第二个身份是加入了创业团队“采光莎莎”，这是一个专注于人的疗愈咖啡品牌，她是早期成员。第三个身份是独立开发者，从Fibe coding开始，一步步摸索，差不多半年时间，现在在探索如何和AI协作，可以称自己为AI Builder或者AI OPC。

Joice在小红书上坚持Building Public，也就是公开构建。她把自己做产品开发的经验、参加活动看到的前沿信息，都发布到小红书上。她已经坚持发布大约四个月，最近保持不间断发布。她认为持续表达非常重要，只有持续表达，才会产生涟漪，遇到同路人和好朋友，也会扩展未来的道路。但是每天想内容很苦恼，所以建议从自己的工作和生活出发，把工作生活的延伸作为内容来源，这样更容易坚持。

关于AI协作，Joice认为一个人加上AI，可以完成过去需要整个营销团队才能做的事情。以前一个营销团队有策划、文案、设计等不同岗位，现在一个人加上AI，从内容策划到营销物料，都可以节省大量时间。虽然不能百分之百替代人，但个人效能大幅提升。她建议不要盲目追逐新模型新工具，导致精神内耗，应该专注于解决自己当下工作和生活中的真实场景。

以下是Joice的内容创作工作流代码示例：

```python
# Joice的内容创作工作流
输入源1 = "X/Twitter上的大佬一手信息"
输入源2 = "个人档案馆：每天自言自语录音，转录为灵感和日志"

    "扫描最近24小时到30天的笔记",
    "根据个人档案语气和关注事项生成选题",

    "生成草稿"
]

输出 = "小红书爆款内容"
```

## 第三节：Mindy的分享：从基金运营到AI个体经纪人🤝

上一节我们了解了Joice从设计师转向AI协作的经历，本节我们来看看第二位嘉宾Mindy的探索道路。

Mindy的背景比较简单。她在澳洲生活和工作了9年，2019年回国。先后在两家公司工作，一家两年，一家六年，共8年，都在做美元私募基金的运营工作。她在投资公司经历过高强度工作，公司使用带有“已读”功能的内部聊天软件，凌晨已读必须立即回复，老板就会知道你还没睡。在这种环境下，她像机器零部件一样运转，工作氛围极度紧张。

去年她偶然接触到数字游民生活，发现可以在大理、三亚海边，拿着笔记本，喝着咖啡，吹着海风敲键盘工作。她非常羡慕这种生活，后来有了AI，觉得这种生活离自己越来越近，可以做出不同的选择。她的价值观发生了很大变化：以前一直以结果为中心，把努力、成就、成绩作为自我价值的核心标尺，规划人生和职场都在一个框架里。看到数字游民的生活样本后，她意识到人生不只有一条轨道，可以是一个旷野，有多样选择。

离职后，她面临一个重要卡点：自己的生存能力和技能已经变成模块化，完全脱离组织直接面对市场非常困难。她是风险偏好很弱的人，在OPC探索过程中有很多顾虑。比如简历空窗期，她过去负责面试招募，很清楚公司对空窗期有歧视态度。如果做OPC没有公司挂靠，空窗期怎么解决？以后还想回归职场怎么办？OPC的可持续性和经济回报也让她担忧。

基于这些思考，她自己定义了一个新身份：AI个体经纪人。她为那些清楚自己想做什么、愿意行动的OPC做经纪人。她非常善于倾听，喜欢和OPC聊天。凭借过去的项目管理经验，她可以同时管理多个管线的工作，和很多人沟通交流，处理财务、市场、时间管理、资源管理等方面的事情。这份工作有点像咨询，但更偏向OPC咨询，是业务咨询、人生教练和心理陪伴的混合体。

以下是Mindy在OPC项目管理上的四条心得：

1. 管理重要但不紧急的事项。在公司里有别人push deadline，作为OPC后，很多重要但不紧急的事情没有deadline，容易被无限期拖延。项目管理时，真正要管理的就是这些事项，会强制性地和OPC一起定deadline，而不是无限期搁置。
2. 谈钱问题。很多OPC不知道怎么谈钱，或者底层对金钱关系不良性。OPC必须处理好与金钱的关系，包括五险一金、保险等风险管理意识，很多OPC对这些概念很薄弱，只关注创收和提高top line。
3. 意义驱动与心血来潮。OPC容易被意义感驱动，但有时只是心血来潮。需要像剥洋葱一样，一层层剖开，问为什么兴奋，热情从哪来，到底想成为什么样的人，不能只靠开心就多做，不开心就少做。
4. 心理陪伴。OPC容易孤独，单打独斗容易产生孤独感。经纪人可以给予心理陪伴，建议加入有温度的组织或圈子，获得归属感，降低孤独感。

## 第四节：月亮的分享：人物展览与社交网络可视化🏛️

上一节我们学习了Mindy作为AI个体经纪人的项目管理心得，本节我们来看看主持人月亮的探索项目。

月亮在超级个体实验室期间，一直有一个念头：做一个线上的人物展览，把打动他的创造者故事放在一个展厅里呈现。以前他尝试用Cursor去实现，觉得困难重重。今年AI发展到现在，他用了一些工具把源代码导出来，继续用Claude Code做进一步呈现，想法终于落地。

他做了两个小小的尝试。

第一个尝试是关于2050学习节的交织故事。2050学习节是一个去中心化生态，从6人发展到千人，经历了三年不断迭代，发生了很多故事。他以前在公众号上发过一篇长文，访谈了8位学习节参与者，每人1到1.5小时深度访谈，讲述他们立体的人生故事、正在做的事业、如何认识学习节、产生的互动和未来。但是长文读起来累，大家注意力分散。现在他用AI把这篇长文变成了交互式展厅，呈现效果更好。

展厅里每个人都是一个节点，最早是6位，第二年拓展到20多位，今年又拓展了更多。每一年的事件发生和发展都变成节点网络，产生各种交织。网络里可以看到不同人之间的连接，比如在访谈中提到另一个人对自己的影响，这就像金丝网络一样不断拓展。下面还有时间线，包含每个人在24年、25年、26年的经历和新体验。

第二个尝试是生命力博物馆。他有自己的播客叫“Becoming计划”，追溯以热爱为驱动的人如何成长。生命力博物馆是一个可持续延展的项目，可以陈列他看到和了解到的独特人物和故事，是一个可探索的展厅。里面会讲到转折点，跟每个人对话哪一个瞬间或哪一件事带来了转变。会陈列教育、家长、志愿者等不同角色的故事，也会有洞察报告。每个人的故事都有自己的节点和成长历程，从小到大的经历，以及每件事情对他来说意味着什么。

未来他计划把其他跟生命力、主动性有关的人物故事共同陈列到生命力博物馆，还会和一些相关的小团队共创。希望这是一个可持续延展的项目，今年会在云南大理办一个线下展览，把AI浪潮下各种实践的朋友、没有走主流路径的朋友的故事带到大理，让还在迷茫中的青少年看到生命的多种可能性和希望。

月亮描述的社交网络可以用下面的公式来表示：

$$
社交网络 = \{ 节点: 人物, 边: 影响与连接, 时间线: 成长历程 \}
$$

## 第五节：OPC成长的核心心法：复利、真实需求与协作💡

上一节我们了解了月亮的人物展览和社交网络可视化项目，本节我们来总结三位嘉宾分享中，OPC成长的核心心法。

三位嘉宾的案例都启发我们，在变动的过程中去寻找那些不变的东西。Joice找到了持续的内容工作台和了解自己，这是一个复利。Mindy关心面对内心和对外协作上的摩擦，如何解决那些有张力的时刻，这也是不变的成长课题。月亮提到持续去表达，把过程性的东西分发出去，让更多人看到你，了解你在关注什么，这也是积累复利。

以下是几条适合初学者的实践建议：

1. 不要被AI工具更新焦虑绑架。现在AI模型和工具迭代非常快，每天都有新功能新产品，很容易让人产生今天学的技术明天就没用了的恐慌。Joice建议OPC不要管外面市场上出现什么东西，只要用能解决当下需求的工具就好。专注于自己真正工作和生活里的场景，和AI一起写作、协作，避免精神内耗。
2. 建立个人内容档案。如果想让AI更好地了解你，尤其是做内容创作，首先要整理你的上下文。你的个人档案就是你的灵魂档案，包括价值观、绝对底线、思维风格、沟通偏好、矛盾点、当前关注、习惯偏好。以前可以存在Notion里，现在可以存在飞书或任何习惯的地方。这对AI来说非常重要，是AI创作的基础。

个人内容档案的代码结构如下：

```json
{
  "价值观": "string",
  "绝对底线": "string",
  "思维风格": "string",
  "沟通偏好": "string",
  "矛盾点": ["string"],
  "当前关注": "string",
  "习惯偏好": "string"
}
```

3. 建立内容工作台，实现从输入到输出的闭环。Joice的工作台有三个输入源：社交媒体一手信息、个人录音档案、播客摘要。有了这三个输入源后，痛点是表达能力不足。她做了一个创作房间，扫描笔记生成选题，套用写作Skill，输出草稿。输入已经有很多笔记，只需要无痛地从输入到输出，就能形成闭环。
