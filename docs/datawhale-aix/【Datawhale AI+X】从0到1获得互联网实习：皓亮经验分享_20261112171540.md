

# 从0到1获得互联网实习：皓亮经验分享：01：课程概述与Sch Me平台介绍 🤖

在本节课中我们将要学习陈浩亮在Sch Me实习的完整经验，包括他是如何拿到Offer的，在实习期间参与了哪些业务，以及对运营工作和求职市场的一些真实感悟。整个分享适合正在寻找第一份互联网实习的同学，尤其是对AI社交和运营岗位感兴趣的朋友。

Sch Me是一款全新的AI原生社交工具。你可以把它简单理解为AI时代下的微信。在这个工具里，你可以使用自己的AI Agent去帮助社交，去匹配志同道合的灵魂伴侣，去寻找新朋友，还可以玩一些AI方面的创新功能。

Sch Me的产品定位可以用下面这个公式来表示：

```
Sch Me = AI原生社交工具 = 类似微信的AI社交平台
```

在本节课开始之前，我们先来看看Sch Me具体是做什么的。以下是Sch Me的核心功能说明：

- 运用AI Agent辅助社交
- 匹配极致灵魂伴侣
- 寻找新朋友
- 体验AI创新玩法

了解完Sch Me是什么之后，接下来我们来看陈浩亮是如何在这个团队实习的。

# 从0到1获得互联网实习：皓亮经验分享：02：获得实习机会的全过程 📝

在本节中我们将重点回顾陈浩亮是如何拿到Sch Me实习Offer的。他的经历告诉我们，主动出击和把握线下活动机会是获得实习的重要途径。

陈浩亮是在Datawhale 2050的11月恳谈会上认识了Second Me的运营负责人郝运。郝运在现场分享了AI时代下个人成长的观点，让陈浩亮觉得这个团队很有意思，于是他鼓起勇气询问是否可以去Second Me实习。最终他成功了，并在1月份拿到了Second Me的实习Offer。

获得Offer的关键步骤可以简化为下面这个公式：

```
获得实习 = 参加线下活动 + 认识负责人 + 主动表达实习意愿
```

在拿到Offer之前，陈浩亮已经有一段产品实习经历，但这次他申请的是运营岗位。他自己认为运营工作对他比较有挑战，因为他觉得自己只有49%的艺人属性，不过他还是决定尝试。

有了实习机会之后，接下来我们就看看他在实习期间主要参与了哪些业务。

# 从0到1获得互联网实习：皓亮经验分享：03：实习期间的主要业务与项目 🚀

在本节中我们将介绍陈浩亮在Second Me实习期间参与的核心业务，这些业务涵盖了线上社交、群聊功能、AI Agent产品以及黑客松活动等。

第一个业务是线上社交墙。这是一个在现场活动中帮助陌生人快速建立社交连接的工具。比如在北京AI活动敲钟环节的最后一天，现场人非常多，甚至挤到门口。通过扫描线上社交墙，参与者可以进到墙上寻找想聊天的人，借助AI Agent完成社交匹配，缓解了排队拥挤的问题，也让大家认识了很多新朋友。

第二个业务是群聊功能。线上社交墙需要由官方搭建，如果用户想在其他活动中拉更多人进墙，是否也要靠官方建？基于这个需求，团队推出了群聊功能。比如在CEO的A2A交流中，大家可以通过扫描二维码进入群聊，并在群里@对方的SE，比如想了解SE最近的进展，就可以@对方，对方会出来回答问题。

第三个业务是Sed Me Book。团队看到Moote Book突然火起来，注册量达到几百万，于是CEO和一个实习生花了一个周末时间，复刻了一个国产版本，叫做Sed Me Book。上线第一天就有1000多个Agent和注册量，一周时间达到了1万多注册量。当时大家觉得这就像重新在做互联网，Agent时代也是从论坛开始重新构建。

第四个业务是全球首届A2A黑客松。团队邀请了来自全球的黑客玩家，观察他们的ID和搭建方式，并举办了这个黑客松。活动结束后还举办了庆祝宴，有香槟和蛋糕。其中遇到了很多有趣的伙伴，比如一个还没上大学的小朋友做了一个游戏，一周注册量达到100；还有外卖员也参加了黑客松并做了项目。最让陈浩亮印象深刻的是牛马模拟器，因为Second Me本身是一个数字分生，在里面可以模拟当牛马的过程，从P1做到P100。

第五个业务是春节期间的A卷小镇，简称SE小镇。这是一个居民证概念的产品，春节期间版本还在持续更新。十字路口的科技也对其进行了分享，阅读量不错。运营效果很明显，三天时间就突破了1万用户，一周甚至更多。这说明Second Me的用户增长越来越有方法。

实习期间的主要业务列表如下：

- 线上社交墙：现场活动社交匹配工具
- 群聊功能：基于二维码的社交群组，支持@SE
- Sed Me Book：国产AI Agent产品，复刻Moote Book
- 全球首届A2A黑客松：全球开发者活动
- SE小镇：春节期间社区运营项目

业务介绍完毕，接下来我们进入陈浩亮对运营工作的三点核心感受。

# 从0到1获得互联网实习：皓亮经验分享：04：对运营工作的三点核心感受 💡

在本节中我们将分享陈浩亮在两个月实习后，对运营岗位的三点深刻体会，包括运营的本质、团队协作方式以及做事闭环的重要性。

第一点感受：运营不仅仅是跟人聊天。之前陈浩亮觉得运营就是跟人聊天，这是一种错误的定位。实际上运营非常考验人，尤其是对比较腼腆、在陌生人场景中不自在的人来说，既考验胆量也考验技巧。一个产品的好坏，不仅取决于研发的功力，还有很大一部分取决于运营成果。比如团队发现一个竞品在春节期间运营做得很厉害，产品也很有趣，能够预判市场需求并提前规划产品线路，这让整个团队面对友商晋升和头部企业做AI社交时压力更小。

第二点感受：好点子需要快速落地，也需要前辈带领。CEO在年会上反复分享库里的名言，you can do all things，重要的事情要说三遍。现在AI模型能力越来越强，每个idea都能快速落地。团队里有不成文的规定，不管是运营还是HR，全员标配CC，每个人都会用Cloud Code。陈浩亮说，只要有一个idea，想用AI去做，就可以快速落地。但是大家idea都能落地，市场化难度反而越来越大。所以团队里有一个见多识广的前辈带着大家做，真的很重要。比如好运哥就是一个很棒的榜样，他带领大家做运营、做策划、做市场推广，对团队帮助很大。

第三点感受：切记半场开箱槟，做事要闭环。陈浩亮在黑客松期间犯了一个大错，因为自己的小错误把一位嘉宾赶走了。当时他觉得嘉宾已经请来了，当天的任务也完成了，任务就算完成了。但实际不是这样，任务完成后还要考虑怎么把事情做得更好，怎么让对方更舒服、更好理解，包括表达上的问题。一定要一步一步扎实地把事情跑下来，这才是完整的闭环。这件事让他意识到自己还是个小孩子，心智和认知上还有很多需要成长的地方。

对运营的三点感受可以总结为下面这个公式：

```
运营感悟 = 运营不只是聊天 + 好点子需前辈带领落地 + 做事必须闭环
```

聊完运营感悟，接下来我们来看陈浩亮关于如何找到第一份实习的建议。

# 从0到1获得互联网实习：皓亮经验分享：05：找到第一份实习的关键与方法 🔍

在本节中我们将讨论为什么第一段实习如此重要，以及陈浩亮推荐的几种找实习的具体渠道。

第一段实习之所以非常关键，是因为它会直接改变你的心态。有了第一段实习经历，你会觉得轻松很多，有一种我已经有一段实习了的感觉，接下来的第二段、第三段实习就会顺理成章。另外，简历上有实习经历，HR会认为你有一些经验，企业更愿意相信你。你对实习的趣味性和流程也会更了解，不再那么恐惧。陈浩亮自己回忆，每次去实习之前都有点害怕，怕做不好、怕犯错、怕不自信，但只要有了第一段实习，就会更有自信去找接下来的机会，甚至有助于最终就业。

找实习的常用渠道如下：

- Boss直聘
- 实习生类招聘平台
- 学校学长学姐的内推码，他们了解你的能力和学校背景，内推可能直接推进同组
- 企业比赛，比如陈浩亮在讯飞的第一段实习就是通过比赛来的
- 线下活动，包括开发者大会、城市活动、2050恳谈会等，可以直接跟企业高管交流，大胆投递简历

除了上面这些渠道，还可以思考如何帮助没有实习的同学尽快找到第一份工作。

简历投递时也有技巧。不要只用默认的打招呼话术，建议写清楚自己来自哪里、是谁、有什么技能、做过什么事情，这样能让HR更快知道你是否匹配JD的要求。另外，HR特别关注你在线简历的内容，不管是Word还是PDF，在线简历的要求会更高。在校期间如果没有参加过比赛活动，也没关系，从现在开始准备完全来不及晚。

渠道和方法介绍完毕，最后我们来聊聊求职过程中的心态与建议。

# 从0到1获得互联网实习：皓亮经验分享：06：求职心态与实用建议 🧠

在本节中我们将总结陈浩亮关于求职心态、耐心和信心的建议，帮助大家在找实习过程中保持积极状态。

找第一份工作或实习，整体来说是非常累的，是一件磨人心性的事情。中间可能会经历两三个月的低谷，找不到工作，处在不断磨合的过程。陈浩亮认为，找到工作最基本的基石是要有信心和耐心，不要被困难打倒，否则容易颓废。状态不好会直接影响面试表现和找工作的状态。

他自己寒假面了两份，第一份实在找不到，此外还面了一个HR。通过观察，他发现Boss直聘界面上HR特别关注打招呼的信息，包括打招呼的内容，他们对线上简历的要求更高。

求职成功的关键要素可以表示为下面这个公式：

```
求职成功 = 信心 + 耐心 + 不断磨合技能 + 优化简历与打招呼话术
```

找工作需要持之以恒，这是一件很费耐心的事情。只要坚持磨练技能，就一定有机会。陈浩亮最后也邀请大家加入他的群一起讨论，如果有其他想法欢迎交流。

以上就是陈浩亮关于求职心态的建议，下面我们来做一个总结。
