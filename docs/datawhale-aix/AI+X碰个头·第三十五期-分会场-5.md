# AI+X碰个头·第三十五期：分会场-5：AI与文学数学交叉实践

👋 本节课我们将学习人工智能在文学创作与数学研究中的实际应用，重点了解大语言模型在写作中的边界，以及出版流程和形式化验证的基础知识。

这节课的内容来自一次分会场的开放讨论。在该分会场里，参与人数较少，所以大家直接开麦交流，不需要像主会场那样进行单口演讲。分享者本身是理科背景，同时也从事人工智能相关的工作，另外还在社区里编写数学教材。通过这次对话，我们可以看到一个从事文学创作和数学写作的人，是如何看待AI技术对传统行业的影响的。

以下是本节课的主要内容。

- 人工智能写小说目前仍处于探索阶段，尚不能直接生成成品。

- 文学创作与数学证明在完成方式上有显著差异。

# AI与文学数学交叉实践：02：大语言模型的伦理对齐与上下文限制

🤖 本节课我们将讨论大语言模型在文学创作中的具体表现，以及它目前面临的主要技术瓶颈。

上一节我们介绍了课程概述，本节中我们来看看AI写小说为什么还不够成熟。

分享者提到，他以前使用过人工智能写小说，但效果不太理想。目前的AI还没有达到可以直接出版成品的阶段，大家更多处于一种预言和尝试的状态。一个核心原因在于伦理对齐。模型在输出内容之前，会先经过强化学习函数的约束，这个过程会让AI倾向于给出主流观点。当出现观点冲突时，模型更容易选择回避，而不是像人类作家那样大胆表达个性化的看法。有些人类可以写出的内容，AI会主动跳过，因为它在上场前已经完成了一定的政治性或伦理性对齐。

以下是伦理对齐的简单描述。

```
对齐后的输出 = 伦理对齐函数(模型原始输出)
```

如果输出内容触碰了敏感边界，模型会选择不回答，或者只给出安全的回答。这意味着AI目前无法替代人类在文学创作中的主导权，它只能作为辅助工具存在。

除了伦理限制，上下文长度也是一个重要问题。在长篇小说创作中，AI很难保持前后的一致性。它可能会出现人物串戏、漏掉字词，或者因果逻辑不连贯的情况。分享者形容，当上下文长度很长时，模型容易发生“上下文漂移”，也就是说，后面生成的内容会逐渐偏离最初的设定，变得平庸，甚至出现重复或矛盾。

以下是上下文压缩的参考经验。

```
压缩率 = 上下文长度 / 50
```

当上下文长度超过某个阈值，比如达到百万级别时，通常需要引入上下文压缩机制，否则前后内容就会出现偏差。不同模型的表现也不同，比如DeepSeek这类模型不是线性注意力机制，推理成本较低，但仍然会对上下文长度做一定的预分配。循环神经网络曾经可以保持常数推理成本，但已经被淘汰；Transformer模型的推理成本有上界和下界限制。

以下是模型推理成本的对比。

```
循环神经网络：推理成本为常数，已被淘汰
Transformer模型：推理成本被上界和下界限制
```

因为每个人的文学功底不同，AI生成的文本很难满足所有读者的审美。如果让所有AI都写得像鲁迅，编辑可能满意，但读者未必会买账。个性化文本生成还有很长的路要走，目前文学领域还没有形成大规模的模型微调和垂类适配市场。

# AI与文学数学交叉实践：03：文学创作与市场让利逻辑

📚 本节课我们将探讨文学作品的本质特征，以及写作和出版背后的市场逻辑。

上一节我们讨论了大语言模型的技术限制，本节中我们来看看文学创作如何与市场需求相互作用。

分享者认为，真正的文学发生在修改过程中。AI更多的是生成一串材料，或者说直接开始编故事，但这不等于文学创作。文学作品需要作者刻意引导，需要留白，需要把因果关系折叠掉或者故意导错，这些都是人类作者的工作，AI很难完成。

文学作品本身没有统一的味道。每个大师都有自己独特的风格，鲁迅有鲁迅的味道，其他作家也有自己的味道。如果所有作品都统一成同一种风格，那就失去了特色，也就谈不上真正的文学了。

写作不仅仅是美学揣测或者社会观察，更多的是一种市场行为。作者为了文学性，可以选择牺牲一部分版税来换取销量；也可以收紧销量，把版税拿回来。这是典型的让利操作。分享者自己编写公益数学教材时，就不考虑市场因素，直接把推理工具和批判工具摆出来供大家使用。

以下是版税与销量的简单关系。

```
作者收益 = 销量 × 单价 × 版税率
```

如果降低版税率，可以提高书的竞争力，从而增加销量，这有助于建立市场口碑。这是出版行业中常见的让利套利策略。

AI时代的到来也给阅读习惯带来了冲击。现在很多读者没有耐心细细品味一本书，文学副刊的影响力下降，大家更多地去书店购买图书。作家协会的新规定也提高了门槛，现在申请作家身份需要五十万字的图书作品，而以前主要看报刊发表情况。

# AI与文学数学交叉实践：04：图书出版流程与选题论证

📖 本节课我们将介绍图书出版的实际流程，以及如何与编辑进行选题沟通。

上一节我们谈了文学创作的市场逻辑，本节中我们来看看一本书是如何从构思变成出版物的。

图书出版不是写完稿子就能直接上架的，需要经过选题论证、三审三教、签订合同等多个环节。编辑在选题会议上需要提交材料，如果作者不能提供充分的选题论证，编辑可能会在会议上被其他同行质疑。为了帮助编辑，作者可以提前准备选题包装材料，甚至像分享者那样，亲手装订一本样书，向编辑展示推广计划和封面设计的想法。

以下是选题论证的核心要点。

```
选题论证 = 社会意义 + 痛点描述 + 一句话推广语
```

编辑看重的是内容，但评估市场潜力需要作者的配合。作者需要向评审会说明这本书为什么好卖，谁是目标读者，以及如何进行宣发。选题本身也会浮动，就像股市一样，今天缺少某种类型的书，明天可能又需要另一种类型，作者可以定期向编辑询问当前的选题需求。

版税方面，分享者的第一本纯文学书籍首印五千本，而纯文学通常首印只有一千到两千本。他与北京的图书公司签订了合同，经过三审三教通过后，书会摆在书店上销售。每个月满一千元会结算一次版税。为了进入市场，他主动让利，把部分版税让给了渠道，例如在抖音批发渠道只收到百分之三的版税，而在自己送到书店的渠道可以收到百分之六。

以下是不同渠道的版税对比。

```
渠道A（抖音批发）：版税率百分之三
渠道B（书店直供）：版税率百分之六
```

这种让利操作的目的是为了提高首本书的销量，建立市场口碑，把第一本书当作进入行业的名片。

# AI与文学数学交叉实践：05：数学形式化验证与机器证明

🧮 本节课我们将学习数学证明的形式化验证方法，以及人工智能在其中的辅助作用。

上一节我们介绍了图书出版流程，本节中我们来看看数学研究如何保证推理的严谨性。

数学写作比文学写作更难。文学作品改个几百遍，一周可能就能完成，但数学证明需要经过机器验证。分享者提到，很多数学研究生在写完论文后，都需要把内容送进验证系统检查一遍。他自己也把手稿送给机器，要求翻译成机器代码，然后通过认证器进行验证。

以下是库里-霍华德对应的简化表达。

```
自然语言证明 ↔ 机器可验证的代码
```

在翻译过程中，有时会出现跳步的情况。机器为了简洁，可能会把作者的一些关键论证省略掉。因此，作者不能完全依赖机器输出，还需要人眼逐行检查代码，确保没有遗漏边界条件或者错误的公理应用。这被称为“瞪眼法”，也就是人肉检查代码。

以下是人工审核的必要性。

```
机器输出代码 → 人工逐行检查 → 确认无误 → 提交验证
```

机器犯错容易被发现，但作者自己的错误很难被自己发现。作者对图书内容承担伦理和法律责任，读者如果发现造假，不会去追查机器人或翻译机器人，而是直接找作者。因此，即使使用了人工智能辅助翻译或证明，作者仍然需要亲自把关。

目前的深度学习模型，比如DeepSeek的证明相关模型，已经有专门的翻译层，可以帮助把自然语言转化为形式化代码。但如果要从零开始学习形式化语言，可能需要一两年的时间，像数学博士生那样每天守着验证机等待结果，过程非常艰难。

# AI与文学数学交叉实践：06：职业发展与跨界选题策略

💼 本节课我们将讨论职业发展建议，以及如何在文学、数学和人工智能之间寻找合适的选题。

上一节我们学习了形式化验证，本节中我们来看看个人职业成长和选题策略。

分享者自己并不认为特别聪明，他强调坚持比天赋更重要。他中学时参加过省级信息学奥赛，后来学习嵌入式开发，也接触过小提琴，最终通过综合分进入中山大学。现在他还在大学就读，没有急于步入社会，他认为日子还很长，不必过早焦虑。

在跨界选题方面，分享者尝试把数学和文学结合起来，但发现同行很难找到。文学同行的出版速度很快，而数学教材的写作周期却很长。他花了一年多时间整理材料，从科学通信稿发展成快报，最后定稿成书，这个过程非常艰辛。

如果要把书推向更广泛的市场，选题需要符合出版商的口味。很多编辑喜欢通俗易懂的科普形式，不用数学、不用代码，直接讲故事，他们认为这样更容易销售。而分享者想写的是更偏向方法论的深度内容，这与市场需求存在一定的冲突。

选题包装需要用一句话概括书的痛点，方便写广告语和封面文案。现代图书产业要求选题论证包含社会意义和痛点，且痛点必须能够浓缩成一句话，才能方便宣传。

以下是选题评估的简单模型。

```
选题价值 = 市场需求 × 作者专长 × 传播潜力
```

# AI与文学数学交叉实践：07：课程总结

🎯 本节课我们将回顾所学内容，并总结人工智能与文学数学交叉领域的核心要点。

上一节我们讨论了职业发展与选题策略，本节中我们来总结整个教程的主要内容。

在这节课中，我们一起学习了以下知识。

- 人工智能写小说仍处于早期探索阶段，无法直接生成可出版的成品。
- 大语言模型受到伦理对齐和上下文长度限制，难以保持长文本的前后一致性。
- 文学创作强调修改、留白和因果折叠，AI只能生成材料，无法替代人类作者的主导作用。
- 图书出版涉及选题论证、三审三教、版税让利和市场包装等环节，作者需要积极配合编辑。
- 数学研究可以使用形式化验证来保证推理正确，但机器翻译可能跳步，仍需要人工逐行检查。
- 职业发展需要坚持和积累履历，选题要兼顾个人兴趣与市场需求，并准备好一句话的推广说明。
