
# 📚 AI+X栖霞山开源知识库教程：第1章：知识库搭建与Agent使用

## 课程概述

在本节课中，我们将学习如何为栖霞山文旅黑客松搭建一个开源知识库。这个知识库相当于栖霞山的“百度”，能够帮助参赛者快速获取景点信息，避免重复收集数据。我们将介绍知识库的核心功能、底层的6A分析框架、数据采集方法，以及如何让智能体（Agent）通过网页接口读取信息。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_5.png)

## 知识库的设计初衷

了解了课程目标之后，我们先来看看为什么要搭建这个知识库。现在的黑客松不再是单纯的编程马拉松，更多像是一个文旅游园会。主办方应该为参赛者提供足够的工具，降低参与门槛。基于这一观察，我们搭建了西峡知识库，让大家跳过百度等搜索引擎的场景限制，直接获取栖霞山的权威信息。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_7.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_9.png)

知识库的核心目标是：把分散的文旅资料集中在一个地方，供智能体和开发者直接调用，节省数据收集时间，让参赛者把精力放在创意开发上。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_11.png)

以下是知识库的主要功能模块：

![](img/e26823a58e4ac6d36d4f74662bedd0fe_13.png)

- 首页：提供景点快速预览和地图导航，标注重点参观景点。
- 红叶预报：根据枫叶红化程度，告诉游客最佳游览时期。
- 浏览地图：支持检索每个景点介绍，查看景点热度和天气预测。
- 景点资料：记录景点位置、名称由来、历史故事等详细信息。
- 内部资料：包含酒店信息、商户信息、菜品信息等，部分数据来自携程和大众点评。
- 地方志资料：整理清朝、民国及不同时代的地方制度和历史文字。
- 调研与规划：包括需求池、产品规划方向、旅游痛点和竞品小游戏分享。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_15.png)

## 核心分析框架：6A模型

![](img/e26823a58e4ac6d36d4f74662bedd0fe_17.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_19.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_20.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_22.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_24.png)

有了建设目标，接下来需要确定知识库的组织结构。为了让知识库结构清晰，我们采用了经典的6A分析法。这个方法来源于卡赫兹的调研方法论，通过纵向时间轴和横向维度分析景点。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_26.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_28.png)

6A模型的六个维度可以用下面的代码结构表示：

![](img/e26823a58e4ac6d36d4f74662bedd0fe_30.png)

```text
景点信息 = {
    吸引物: 标志性建筑、打卡点、文化景观,
    交通: 怎么到达景区、内部交通方式,
    配套: 吃喝住行、周边酒店、餐饮商户,
    套餐: 门票价格、园内活动收费项目,
    活动: 景区举办的节庆活动、互动项目,
    辅助服务: 游客中心、卫生间、紧急救助等基础服务
}
```

![](img/e26823a58e4ac6d36d4f74662bedd0fe_32.png)

有了这个框架，我们就知道应该收集哪些基本信息。无论是面向游客、面向景区还是面向政府的产品，都可以在这些基础数据上进行上层开发。大家可以根据自己的角度来判断，我们只需要提供最基础的数据，就能让各种不同的产品都能使用。

## 数据采集与构建流程

![](img/e26823a58e4ac6d36d4f74662bedd0fe_40.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_42.png)

框架确定后，实际工作就是去填充数据。构建知识库不是一次性的工程，而是需要不断迭代积累。数据采集分为以下几个阶段：

![](img/e26823a58e4ac6d36d4f74662bedd0fe_44.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_46.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_47.png)

以下是数据来源的分类：

1. 冷启动阶段：通过百度、谷歌等搜索引擎全网检索，补充政府网站、官方公众号、本地生活平台的公开信息。这一阶段比较暴力，但能快速把景点基础信息“洗”出来。
2. 热启动阶段：从携程、美团、大众点评等平台获取聚合数据。这类数据被困在数据孤岛中，需要专门的采集手段。
3. 文化书籍阶段：查阅学术文件、地方志、历史书籍，补充文化底蕴相关内容。
4. 实时媒体阶段：借助hoopAI等架构，通过实时流媒体持续补充最新信息。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_49.png)

在实际操作中，我们首先确定了20个标志性景点，然后围绕这些景点补全相关信息。每个资料卡都标注了出处，目前已经整理了34个资料卡，包含3个历史大事件来源，以及52张图片。图片的后期整理仍有提升空间，后续可以投入更多精力进行打磨。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_51.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_53.png)

## 内部数据与访问控制

![](img/e26823a58e4ac6d36d4f74662bedd0fe_55.png)

在采集公开数据的同时，还有一部分需要受限访问。知识库中包含一些不能公开的商业数据，例如从携程和大众点评爬取的商户信息。这类数据受版权保护，只能在比赛内部使用。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_57.png)

为了解决这个问题，我们在基于Cloud搭建的平台上增加了邮箱登录机制。用户只需填写验证码即可完成简单注册，登录后才能查看内部资料。内部资料点进去后，系统会生成一个口令，智能体持有该口令即可拉取内部信息。

以下是内部资料包含的内容：

![](img/e26823a58e4ac6d36d4f74662bedd0fe_59.png)

- 酒店信息和周边商户信息
- 人均消费和客群画像线索
- 群友共享的开源资料
- 历史故事和典故原文

![](img/e26823a58e4ac6d36d4f74662bedd0fe_61.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_63.png)

## 如何让智能体使用知识库

数据准备好了，就要考虑怎么让智能体读取。知识库最大的亮点是面向智能体设计。我们只需要把网页地址给智能体，它就能找到接口文件，通过功能读取我们的信息。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_67.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_69.png)

以下是具体的使用步骤：

1. 打开一个智能体对话窗口。
2. 把知识库的网页网址发送给智能体。
3. 告诉智能体在该网页中查找特定信息，例如“栖霞山有多少个卫生间”。
4. 智能体会调用网页中的数据接口，直接返回答案。

![](img/e26823a58e4ac6d36d4f74662bedd0fe_71.png)

![](img/e26823a58e4ac6d36d4f74662bedd0fe_73.png)

在演示中，我们曾让智能体查询栖霞山卫生间数量，它能够通过网页接口快速得出结果，避免了手动搜索的等待时间。不同的智能体都可以使用这种方式，关键在于数据已经被结构化整理。如果大家觉得直接搜索太慢，可以把网址发给智能体，让它在网页里面查找，这样更快捷。

## 开源精神与后续迭代

工具可以用了，背后的理念也值得说明。我们希望把数据做成“公路基建”，谁都能用，谁都能补完。开源精神的核心在于：每个人都可以使用这个知识库，但它不属于任何一个人。所有作品都可以通过接入我们的数据库获得更好的数据，从而把精力放在开发上。

目前知识库还存在一些不足，特别是图像和音频资料较少。后续可以引入小红书等平台的图片，丰富多媒体内容。同时，知识库的价值不在于初始架构，而在于不断的迭代积累，今天有数据、明天有数据，才能真正发挥作用。大家也可以像维基百科一样，把自己找到的资料上传到知识库，供所有人共享。
