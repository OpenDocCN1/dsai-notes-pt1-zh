

# 🎓 AI赋能大学生：实习该怎么找？：1：AI高效对话与提示词公式

在本节课中，我们将学习如何与人工智能高效对话，掌握一套可复用的提问公式，从而显著提升使用 AI 的效率，为后续的内容创作和实习求职打下基础。

我是郭晨，河海大学2023级本科生，也是一名AI博主，同时是counts新社的发起人之一。counts新社是一个聚焦南京地区的大学生AI社群。今天的分享我会围绕AI工具、内容创作和社群连接三个方面展开，重点聊两个话题：第一个是如何提升AI效率，包括如何与AI高效对话，以及如何用AI工具赋能大学生活；第二个是大学生加AI加自媒体，探讨在AI时代做自媒体是一个好选择，以及如何用AI为自己的自媒体提升效率。

先来看第一部分：如何与AI高效对话。刚开始使用AI的时候，我自己也显得非常笨拙。我会跟AI说一些模糊不清的话，比如“帮我写一个AI，分享关于这个的PPT”，或者让AI做一些没有边界的模糊事情。当这些请求无法被拆分成细致的目标时，最终产生的结果往往非常不理想。所以，我们需要一套高质量的提问方式。我总结出了一个提问公式：

```text
目标 + 背景 + 已有材料 + 角色 + 限制条件 + 参考样例 + 输出格式 = 高质量提问
```

举个例子，如果我想让AI做一个8到9页的AI分享PPT，背景是大学生直播，以聊天为主，我可以把我写的原始提纲作为已有材料，并设定边界限制，比如不做真实演示，不是按我给的核心观点，最终输出的内容包括每页标题、核心观点和画面建议。再比如，我们今晚要做西红柿炒蛋，怎么向AI提问？目标是做一个西红柿炒蛋，背景是用于今晚的晚餐，我想吃清淡一些。已有材料是一个西红柿、一堆鸡蛋和一些调料。限制条件是做得清淡一点，比如我有忌口，不放葱姜。输出要求是为我输出一份色香味俱全的西红柿炒鸡蛋。这样一来，就完成了一个高质量的提问。

当我们给AI的上下文越具体时，AI就越容易抓住真正的问题。因为我们现在遇到的很多问题，其实都比较短，而现在的AI上下文已经训练到非常恐怖的地步，包括把《红楼梦》或者托尔斯泰的小说扔进去，它都能完全读取。所以，在日常生活中使用AI时，尽量多给它上下文，尽量多给它背景。

那么，为什么我们要这样跟AI对话呢？因为现在的大语言模型，就是根据上下文继续生成可能出现的下一个词。这个过程是这样的：我们输入问题，然后进行分词，也就是词元化，之后将词元映射成相关的向量，接着计算它们之间的关系，再经过一个函数变化，就能输出下一个词。模型最初接收的是一串词元，它预测的下一个也是词元。如果没有词元，注意力机制就无法开始。所以说，我们输入的内容就是处理的起点。给AI足够多的好东西，我们才能得到更好的结果。

这里有个梗图，说的是“缰神在抓住我”，意思是我们不能给AI一些很玄乎的请求。之前有个笑话，有人告诉AI：“为我成立一家价值10亿美元的公司，在成立之前不要停下来，等你做好了再叫醒我。”这种奇怪的目标，AI就无法达成很好的输出效果。因此，我们需要把目标做得更细致、更量化。这也类似于AI圈里鱼皮开源的一个scale，大家可以去获取，用于自媒体分享或自己的学习。

# 🎓 AI赋能大学生：实习该怎么找？：2：AI工具赋能大学生活

上一节我们介绍了如何与AI高效对话，以及提问公式的使用方法。本节我们来看看AI工具如何具体进入大学生活，帮助大家完成课程作业和学生工作。

今天我主要讲两个工具：一个是腾讯的元宝，一个是Coze。腾讯元宝大约在7月底上线，是一个很有趣的应用，虽然注册相对有一些限制，但它的亮点在于可以调用Imagine2模型，也可以调用谷歌的Banana系列模型，直接使用即可。注册时会送一些积分，兑换下来大概相当于70块钱的成本。用这个工具，可以做出非常不错的东西，比如PPT、课程汇报和海报。

大学新生进入校园后，会面临很多学生工作，往往需要制作大量图片。有些图片可以用可画来做，有些用可画上手比较困难。这时候你可以调用腾讯元宝中的Imagine2，这是目前世界上最强的图像生成模型之一，就能做出相对不错的效果。用了之后，辅导员和带教老师一定会狠狠地夸你。

接下来是Coze，也就是大家常说的“欧巴地”。我想强调的一个方法是，把我们之前的一些重复指令，变成一种独特的学习经验和具体方法。具体的步骤是这样的：

第一步，和AI进行足够多的对话之后，找出其中的重复任务。

第二步，提取共同的规则。找出共同的要求。比如我们之前总让AI做PPT，那我们做PPT的要求是什么？市面上有很多做PPT的工具，但每个人的需求不一样。比如我做PPT可能喜欢橙色和绿色的底图风格，有人喜欢更艺术的字体，有人喜欢拼接风格。针对这些差异，我们需要提取出共同规则。

第三步，把这些规则拆解成可复用的结构。因为我们之前强调要给AI足够的上下文，把内容拆解成可复用结构非常有必要。虽然AI现在已经很智能，但如果你给它更结构化的输入，它读取的效果会更好。你可以给它触发条件、输入参数、执行步骤、输出格式等等。

```text
{
  "触发条件": "用户需要生成PPT大纲",
  "输入参数": "主题、页数、风格偏好",
  "执行步骤": "1. 分析主题；2. 拆分章节；3. 生成每页标题和要点",
  "输出格式": "Markdown大纲，包含页面标题、核心观点、画面建议"
}
```

第四步，有了这三步之后，把它封装成一个scale。第五步，把这个scale放入对应的Coze中。第六步，也是很重要的一步，对它进行测试迭代。每次做出的scale不可能一次就完善，一定要多次修改完善，比如1.0版本、1.0.1版本。每一次更新都是你个人成长的体现。

scale本质上就是一个系统化的提示词。做scale的门槛很低，只要你会基本的AI工具和功能，就能做出一个还看得过去、能够正常使用的scale。但是，真正做出高含金量的scale是一个难度非常高的过程。因为一个scale本身是一个具体领域的人，在这个领域拥有大量经验的集合。比如有人做电商，你问AI怎么做电商，它能给很多很棒的答案，但这些答案不一定适用于真实市场。而如果有一个人专门做这个领域，他会把这些经验沉淀下来，沉淀成提示词。这些提示词非常宝贵，在于个人的经验，在于对真实世界的真实体验。这也跟近几年火热的世界模型有关，就是强调要有真实的经验，对真实世界的感受和体验，之后做出的东西才更符合真实世界。因为AI不管是画图、生成声音还是生成视频，本质都是基于大语言模型做预测，而真实的实践经验是非常可贵的东西。

# 🎓 AI赋能大学生：实习该怎么找？：3：AI时代大学生做自媒体的价值与方法

上一节我们讲了AI工具在大学生活中的应用，本节我们来聊聊为什么在AI时代，大学生做自媒体是一个很好的选择。

做自媒体不一定非要有很多粉丝，哪怕只有10个、50个、100个关注者，甚至只有两个人关注你，只要你开了账号并开始分享，我认为这就是一个自媒体。做自媒体会带来很多好处。

第一个好处是，可以用输出倒逼我们自己的学习。我们常讲的费曼学习法，就是学会一个东西最好的方式，是把它讲给别人听。把学习AI的过程写下来、录下来，我们肯定会遇到志同道合的人。比如我今天学会了如何更好地向AI提问，然后我就把它分享出来，分享成一篇笔记、一篇公众号，甚至录一个视频。这样一来，一方面锻炼了视频表达能力，另一方面可以更好地巩固知识。三五年之后，如果那个网站还在，你看到以前的视频，也会觉得自己有了非常大的成长。

第二个好处是，可以用输出倒逼自己思考。比如你给自己定一个量，每周五晚上一定要更新一篇公众号，或者每天晚上要发出学到的一些东西。无论有没有人看，都坚持发。这样一来，每天晚上都会有一个KPI焦虑，这个焦虑会倒逼你去学习。比如今晚的东西还没发，怎么办？那就得赶紧去学一个东西，虽然学得效果可能不尽人意，效率不高，也不完善，但只要把它发出来，就一定会有人鼓励你。如果学得不完善，有人会批评你，甚至批评得很尖锐，甚至会对你的人生进行攻击，这些都是能很好锻炼我们成长的过程。用输出倒逼自己思考，把自己曝光在更大的检验场景下，获得更高的质检。因为网络现在本质上就是一个质检平台，不管上面的网名质检员素质高低，它都是一场质检。

第三个好处是，人与人的沟通越来越重要。比如我们在南京的counts新社，我和几个小伙伴最初就是在网络上认识的，网络功能为我们提供了一个很大的平台。我们在不同的社区中可以遇到不同的人，这些人能带给我们正面影响或负面影响，但总归是在推动我们朝着改变的方向进化。只要走在进化路上，就是好的。

我最近写了两篇公众号，就是和AI讨论之后输出的文章。关于排版，有一个很好用的方法：用飞书，然后做公众号排版。具体来说，你可以把AI接入飞书的CLI，在飞书里写入内容，然后用飞书里的公众号排版Pro插件，安装好之后，就可以直接一键复制到公众号，形成很好的排版。因为我发现目前市面上公众号排版的软件还是蛮贵的，好多收费一个月三四十块钱。而用飞书的格式，暂时是不需要收费的，还是免费的过程。在AI时代，每一分钱都非常宝贵，我们要把最多的钱用在最高效的地方，把这些钱省下来，可以用来充值。

持续输出会慢慢改变我们的学习思考，以及我们在社会中的关系，让我们认识更多的人，接受更多的曝光。

# 🎓 AI赋能大学生：实习该怎么找？：4：AI辅助长文写作与个人知识库搭建

上一节我们讨论了做自媒体的价值，本节进入具体的写作方法和知识积累，看看如何用AI辅助写长文，以及如何搭建个人知识库。

目前很多AI相关的公众号被平台处理过，因为很多人用AI去写公众号来赚取保底收入。公众号写文章是有收入的，读者点了广告之后，作者就有收益。这导致公众号现在AI文章泛滥，出现很多破折号、很多双引号，很多观点都非常平均，把AI当成可以干活、可以保工作的东西，还爱用一些奇怪的比喻，比如“AI现在不是实习生了，是可以帮你干工作的正直”。还有GPT经常用的“文本接住你”，豆包常用的“用最真实最不绕弯最大白话的方式告诉你”。直接用AI写长文不好，一方面把自己的脑子外包了，另一方面给平台带来了很多垃圾，我愿意把这些东西叫做社交平台上的AI干水，没有自己的思考，全部是AI输出的内容。

前面我们讲过，大语言模型输出的东西肯定是概率预测的，概率预测的东西就是一个趋于平均的东西。趋于平均数的东西，就不会那么出彩，就会缺失你的风格，缺失你的观点。它会给出一个非常平均的东西，这个平均的东西会消磨我们很多自己的观点和锐气。

那么，怎么用AI去辅助写作呢？第一点是追问盲点。比如你问了AI一个问题，你哪些东西不清楚，就接着追问。第二点是补充角度，你可以让AI帮你补充角度。第三点是你自己去补充一些角度，还是以西红柿炒鸡蛋为例，做的时候你可以告诉他，南方和北方的做法不一样，山西和山东的做法不一样，这些很细节的东西可以丰富内容。第四点是提供反例，你可以和AI进行辩论，比如豆包现在有一个辩论模式，ChatGPT更新之后也有一个深度研究模式，这些模式已经无限接近真人，你可以和它们沟通交流，让它们尽量当杠精。和AI锻炼吵架也是一个很好的方式，当然，不要用过度尖锐的语言去骂你的AI。因为在今年1月份有一篇论文报道，说AI的原生家庭会决定它之后怎样发展，当你过度骂一个AI的时候，它之后输出可能不会那么优秀。当然这是一个比较玄学的说法，大家就当一个梗去听就好了。

在完成AI帮我们完成的追问盲点、补充角度、提供反例之后，我们接下来进行对话筛选重写。然后我们来继续选择观点，核实材料，写出自己的表达。我们选观点的时候，选我们自己真正想去表达的，而不是AI给我们的一个很平均的观点。因为现在的AI都有一些记忆功能，如果你开启记忆功能，它就会把你之前处理的一些任务关联起来。比如你今天要写一篇西红柿炒鸡蛋的文章，但你之前在AI里问过便秘怎么办，那么它现在就会把便秘和西红柿炒鸡蛋联系起来，这样联系起来的话，结果就会非常糟糕。所以我们需要用自己观点先给AI做一个框架。

第二点是核实材料。如果开启联网搜索还好，如果不开联网搜索，因为每个AI的大模型训练数据截止日期不一样，有的可能截止到2026年，有的甚至只截止到2025年的某4月份。如果说你用这个去判定，就会出现很多啼笑皆非的事故。就比如某些名人可能在2026年不幸离世，但AI会言之凿凿地告诉你，他还没有离世，是在胡说。所以核实材料也是很重要的部分，包括AI会出现很多幻觉，这些幻觉需要我们进行更仔细的研究。抖音上有个段子，说你问豆包，第一遍问，第二遍问，第三遍问，每次语气不一样，答案也完全不一样。遇到这种情况，显然这些东西需要我们自己去核实。你还可以让AI互相质检，比如在豆包输入，它给你输出材料之后，你让Kimi去质检，Kimi质检完之后，再让DeepSeek质检一遍，让大家互相鞭策，形成互相监督的链条。

第三个部分是要写出自己的表达。因为每个人的表达方式不一样。之前我试过市面上所有的模型，包括Claude等，尝试用它们去蒸馏我的文风，我把写过的上百篇公众号文章输入给它，但它最后蒸馏出一份scale，我用这份scale写的东西依旧非常烂。很多时候，现在的AI无法代替真人表达，它可以代替编程，代替很多其他创造，但就写作这一项，即使是一个接受过九年义务教育的人，也能判断出一个东西写的有没有人味，有没有AI味。很荒诞的是，AI进化到今天，原以为门槛最低的AI写作，现在反而成了靠直觉、门槛相对更高的工作。当我们把AI当做思考陪练的时候，我们的文章才会留下自己的痕迹。所以我也非常期待和鼓励大家用AI辅助自己写长文，然后自己认真去改长文，认真和AI去碰自己的观点。

接下来推荐一个腾讯的工具，叫im码（I码），可以把我们之前所做的内容总结成知识库。当我们和AI聊得足够多的时候，如果你用的不是专业版本或模式，有些东西就会出现零散，或者说组织不够完善。谷歌生态有Notebook LM，而我们这里用腾讯平台的im码会相对好一些。我之前把所有公众号文章导入到im码里面，最后呈现的效果非常好。

我们可以把日常的一些观察、对话记录、案例拆解，整体归类下来，进行筛选、归类、建立关联，建立成我们自己的知识库，建立一份素材库，建立一份知识库。比如之后你做自媒体，或者去学习一些新知识，你可以把之前的课本全部导入进去，把它拆成很碎的块，拆成一张一张的，然后每张拼起来就会得到一个新的观点。比如你要写一篇论文，就把之前收集到的观点拆成很多个素材，把这些素材像词元一样组合起来，就会组合出很多意想不到的可能。知识库保留从我们的观点框架与方法，把这些东西做一个总的汇总之后，我们可以把它再次用于写作、分享和复盘。某次回答可能会忘，但是长期积累下的知识系统不会忘，你可以把它们导入到WPS或者其他工具里面，做一个长期的自己的知识库，让自己成为一个有长期成长价值的人。

# 🎓 AI赋能大学生：实习该怎么找？：5：零经验大学生如何找到第一份实习

前面几节我们学习了如何用AI提升效率、如何做自媒体，以及如何积累知识。本节我们转向大家非常关注的实习问题，看看零经验的大学生如何找到第一份实习。

我是贾振贺，counts新社的发起人。大一的时候我积累了四段实习经历，包括运营、江苏春晚元宵晚会、以及字节跳动等大厂的工作。今天主要想告诉大家，怎么在大一这样一个没有经历、没有经验的年级，找到自己的第一份实习。

很多同学现在的状态是这样：打开招聘软件，岗位有很多要求，写着要有相关经验。但我们回头看自己的简历，除了课程、社团、学生会这样的经历，没有一段能够真正称为工作经验的信息，就是能够真正写在简历上面的一些信息。

我想跟大家说一个结论：所谓的零经验，不等同于大家什么都没有。很多时候，我们可以把之前做过的课程经验、课程作业、校园活动以及个人作品和团队协作都润色，然后整理成HR或者公司方能够听懂的一些信息。

今天主要讲四个内容。第一个，今年的实习市场到底变了什么。第二个，我在四段实习和大型项目现场学到的经验是什么。第三个，没有经验，怎么能够让AI或者我们自己写出第一份简历。第四个，介绍一下我们的社区。

先来说说今年的实习市场三个变化。首先，岗位更细。比如之前做过的一些运营岗位，或者市场品牌岗位，可能从原来的整体运营，拆分成了现在细化的领域。现在的运营大多是直播运营、新媒体运营这种更垂类的岗位。其次，筛选更早。大家在提交简历的阶段，很大程度上已经被筛选了好几轮。因为现在大多数公司都有自动筛选简历的程序，会自动筛一些条件，比如实习经历，如果竞争激烈，就只剩两段实习经历的人。再次，信息更分散。为什么这么说？因为现在大部分人不知道机会在哪里找，同时AI又改写了初级岗位的要求，越来越多的应届生觉得AI的新岗位招聘信息不明晰。用大白话讲，就是老板想要会AI的人，但大学生们不知道老板要什么，通过招聘网站上的内容，也很难看出公司真正要的是什么。所以说现在有一个大问题，就是信息差。大家面临的很大问题，就是没有经验，这是一个死循环。网上都说招聘实习要有经历的人来应聘，但我们在校园里没有这样的经验，应该怎么打破这个死循环？

国家这边也有相关信息。教育部有百万大学生实习促就业计划，中国青年报调查显示，60%以上的学生对AI的新岗位都不明晰。还有青年就业服务的攻坚行动。所以说，国家整个教育部和就业市场，还是希望能够有AI新岗位的人才，包括其他岗位的招聘机会出现。大家不用担心岗位消失，我们完全有机会。但是首先要有一份真实且对口的简历。

那么简历怎么写呢？首先，可以写课程项目。比如我们做过调研、数据整理、方案设计、展示汇报，网页或者程序，都可以列到备忘录里。第二，校园活动。包括社团、比赛、迎新、讲座、直播、志愿活动、班级项目。重点不是这一段经历出不出名，而是你有没有负责其中的一些环节，比如报名、宣传、现场协作。第三，个人作品。自媒体账号、视频、文章、海报、网页，在GitHub上的开源项目，都可以成为简历上很有含金量的证据。只要你真的做过，并且别人能打开、能看到、能理解，就比一句“我对这个方向感兴趣”或“我比较适合这个方向”更有说服力。第四，帮助别人完成的一些事情。比如帮社团做表格，帮朋友剪视频。要有交付、有过程，这样也能作为实践素材。

在盘点这四类大类的时候，不要只写宽泛的结论，比如“我负责了运营，我有沟通能力”。我们要说动作。比如在这个报名环节，我收集了什么，整理了什么，联系了谁，做了哪一版，交付了什么。我们要有一个从0到1的交付环节。

零经验时最容易踩的坑，就是简历上写“什么岗位都可以”。首先，投各种岗位时，我们一定要定向优化简历。就我自己而言，投运营岗位，我会写一份运营岗的简历，投市场岗位也同理。如果HR看到“什么岗位都可以”，他不知道你能做什么，也不知道把你放到哪个岗位。所以说，我们可以先选一个方向做一个7天的实验，比如内容运营、活动运营、产品助理。选好方向之后，去看三个真实的岗位，把岗位描述中的动词圈出来，比如整理、分析、跟进、协作。岗位名称可能不一样，但实际工作动作比较接近。

然后问自己三个问题：我已经做过哪些动作？我还缺少哪一个最小的能力？我能不能在7天里做成一个小的结果，也就是小MVP？第一份实习不需要证明你已经能胜任这份工作，只需要证明你能理解这个任务，并且完成其中的一小段工作就可以。

下面讲一下我的四段经历。第一段是新媒体运营，主要做直播运营和内容策划。第二段是在传统媒体，江苏电视台做省级歌手大赛的运营。第三段是江苏春晚元宵晚会的综艺导演组。第四段是直来直往导演组，做流程管理和风控管理。

在这些工作中，最后都应该留下一点东西，比如一段脚本、一张流程表、一份数据记录、一套物资台账。我们最后要有一个最终交付的作品。所以在做第一段实践时，要扪心自问，一周之后向别人解释这件事情，我能拿得出手的经历是什么。

以直播运营为例，很多人理解直播就是出镜、搞气氛，但真正做下来，直播是一个不断观察、调整、优化内容的过程。直播后，抖音官方平台会看到观众留存率，代表观众何时离开，就可以判断出什么时候讲的内容能留住人，哪句话需要回应、加强互动。这些都要从数据和现场判断。我做的一件具体事情是，把直播过程拆开，看观众在哪些位置流失，再针对性地调整脚本和互动节奏。同时我也做选题、拍摄、发布和数据复盘，完成了30万以上浏览量的视频，以及用户增长和转化工作。

针对这样一段经历，能写进简历的事情，首先要问自己：用户是谁，问题是什么，采取了什么动作，最后发生了什么变化。

第二段是校园活动类运营，让我更快理解一条完整的链路：确定吸引谁，设计内容和互动，最后发布，定期根据反馈数据复盘。第三段是大型节目现场，当时在江苏春晚元宵晚会，我的收获是要把控细节。细节不是把表格做得好看，而是在关键时刻，你能不能准确知道要的东西在哪里，谁在使用，下一步什么时候需要。在真实项目里，最容易被记住的，往往是让别人放心的人。所以工作中首先要保证可靠性，交付给别人时要有时间观念，这是最基本的。同时交付时要自己审核，发现问题尽早说，任务变化及时调整，结果交付清楚。

第四段是节目运营到流程运营，在直来直往导演组参与人员筛选、风险控制和多方协调。流程可以分为几块：报名、面试和确认。这类工作让我发现，很多人写简历时会写沟通能力强、执行能力强，但这些词太宽泛。真正的流程运营是把容易弄混的事情拆成明确具体的步骤：每一步有什么标准，由谁负责，什么时候完成，怎么判断通过。如果一件事只能靠某个人的经验推动，就很难复刻、复制。如果能整理成表格、文档和清晰标准，别人也能照着做，这才有了流程的价值。

最后总结一下，没有实习，怎么先做出实习经历。第一类是课程项目，比如在课程组、某门课或实践课上担任职位，做调研、数据分析、产品、视频，都叫课程项目。第二类是校园活动，在学生会或班级活动中，包含组织、宣传、流程和现场执行。第三类是个人作品，比较宽泛。第四类是和别人完成的事情，社群、比赛、志愿活动、小型创业项目都可以。

盘点之后，每一项都要用四句话来重新描述。第一句，当时面对了什么问题。第二句，你具体做了什么。第三句，最后留下了什么结果。第四句，下一次对这样一致的工作会有什么调整。不要只说“我参与过一次校园活动”，可以说：“当时活动报名不足，我负责报名内容和现场流程，最后留下了一套可以复用的活动方案和执行表。下一次会提前验证报名渠道。”一份完整方案、一套流程表，都可以成为简历上证明能力的证据。

# 🎓 AI赋能大学生：实习该怎么找？：6：AI辅助求职与成长社区介绍

上一节我们学习了如何撰写零经验简历，本节介绍AI如何辅助求职，以及如何通过社区从学习走向实践。

AI能帮你加速，但不能帮你编造经历。AI能帮你的五件事。第一，拆解岗位。比如在小红书或BOSS直聘看到实习岗位，把JD截图给豆包或Coze，让它拆解工作需要的能力和协作要求。第二，整理经历。可以用语音模型，跟AI讲从开学到现在做了什么，让它梳理。第三，找出和目标岗位的连接性。第四，补齐能力。拆解JD并分析自身经验后，AI会告诉你还需要补充什么能力。第五，模拟面试。把JD或人才条件发给豆包，让它当模拟面试官，进行语音沟通，还能对面试进行复盘。第六，复盘工作。做了什么，卡在哪里，下次怎么调整。

使用AI时要注意三点：没做过的项目不要写成已经做过；没有负责过的内容不要夸大；没核对过的数据，不要让AI简单放进简历里。最后给大家一个7天的小建议。

接下来介绍一下我们的社区。counts新社是由我和四位同学一起发起的，面向南京高校学生的一个AI社区。社区活动范围在南京和武汉两个基点。社区从6月份从零开始启动，前期48小时从零增长到了240人，首日自然增长了100多人，将近200人。每日活跃度稳定在30%以上，用户自发产生了20多条内容。但是和其他社区不太一样，我们不太看重这样的数据。我们为什么叫counts新社，希望在AI时代，每一个还未连接的人，都是夜空中的一颗星星。我们希望有一个能够让我们交流、让人与人产生连接的平台。增长之后，能不能让人留下来，真正发生交流，能不能让一个小demo、一个小项目继续往下走。所以我们搭建了几个机制：新人欢迎和自我介绍，每日AI资讯报道，每周总结，晚间主题讨论，周末案例拆解，打卡，老成员带薪活动。

在南京最大的感受是，很多同学缺的是信息差。网上教程良莠不齐，大家更缺少一起行动的人，能给反馈的人，以及一个小想法能从0到1完善的环境。我们的社区就是想让大家从“我想学”走到“我想做”，再走到“我想找机会”。你可以带着一个问题来，也可以带着一个项目来。欢迎大家扫码进入社区。

最后总结一下。对于2026年实习就业市场，我的判断是机会还在，但是判断方向变了。岗位变得更加想要一个垂直领域、有垂直领域经验的人。没有实习，我们可以用另外的方式来积攒简历经验。希望大家先做一个小项目，不管怎么样，先迈出第一步来积累第一个经验。
