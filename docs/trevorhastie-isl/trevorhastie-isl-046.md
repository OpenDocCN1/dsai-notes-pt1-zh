# 46：非线性模型拟合 📈








在本节课中，我们将要学习如何将非线性函数和模型引入到我们的分析中。到目前为止，我们主要关注线性模型。你将看到，以一种近乎无缝的方式将非线性引入模型实际上非常容易，并且所使用的工具几乎和我们拟合线性模型时一样简单。




我们将讨论一系列方法，从完全直接的方法到稍微复杂一些的方法。今天介绍的一些内容，对Trevor和我来说，甚至有些历史意义——我们合作撰写的第一篇论文就是关于“广义可加模型”的。在本节的最后部分，我们将讨论广义可加模型，这是一种将非线性工具用于多个预测变量的方法。






## 为什么需要非线性？🤔



首先，一个事实是：真相从来不是线性的。这对于统计学教授来说可能是一个令人震惊的说法。或许我应该修正一下：真相几乎从来不是线性的。线性是一种近似。通常，线性假设已经足够好，这也是我们喜欢线性模型的原因——近似足够好，并且能给我们一个简洁的总结。但我们常常需要超越线性，并且我们有很多工具可以做到这一点。本节我们将讨论其中的一些。







以下是我们要介绍的方法列表，其复杂性随着列表向下而增加：
*   多项式回归
*   阶梯函数
*   样条
*   局部回归
*   广义可加模型





你将看到，它们和线性模型一样易于使用。




## 多项式回归 📊





多项式回归我们之前其实已经介绍过。当我们引入这些非线性方法时，大部分情况下（除了讲到多变量的广义可加模型）我们会以单变量为例，但你会看到在多变量上应用也同样简单。



多项式回归模型不仅包含线性项，还包含多项式项，例如 `x^2`、`x^3` 等等，我们可以达到任意想要的阶数。对于线性模型来说，它在系数上是线性的，但它是 `x` 的非线性函数。







在左侧面板中，我们看到在工资数据上，一个多项式函数被拟合到年龄变量上，我相信那是一个三阶多项式。你可以看到拟合的函数以及逐点的标准误差带（这些虚线带，表示正负一个标准误差）。这是一个非线性函数，似乎捕捉到了数据中的趋势。我注意到标准误差在两端更宽，这是因为数据在两端变稀疏了，所以用于拟合曲线末端的信息要少得多，因此标准误差变宽。此外，多项式是一个非常灵活的函数，尤其是在末端，这些“尾巴”往往会摆动，标准误差带也表明了这一点。





实际上，在右侧的图中，我们使用多项式来拟合逻辑回归。为此，在本节中，我们通过观察工资是否大于250K，将工资转换为一个二元变量。这是一个逻辑回归，试图对该事件的概率进行建模。请注意末端的标准误差带有多宽。虽然我最初看到时觉得不可思议，但后来我意识到纵坐标的尺度被拉伸得很厉害，它只到0.2。如果你从0到1来看，它会显得窄得多。这是一个需要时刻牢记的点：绘图尺度很重要。正如Rob所说，在这种情况下，它只到0.2。你还会注意到这里有一个所谓的“地毯图”，在图的底部我们看到所有零值出现的位置（这些小尖刺），它们均匀地分布在整个范围内；在上方我们看到所有一值出现的位置，你会注意到中间只有一个，末端没有多少一值。所以实际上在末端根本没有数据来估计这个函数。





### 多项式回归的细节




具体来说，进行多项式回归时，你需要创建新的变量，在本例中，它们只是原始变量的变换。所以对于 `x`，我们令 `x1` 是原始的 `x`，`x2` 是 `x^2`，依此类推。然后，只需将问题视为一个具有这些新派生变量的多元线性回归模型。





在这种情况下，我们并不真正关心系数本身，我们更关心在任何特定值 `x0` 处的拟合函数。我们关心的是组合后的函数。一旦我们拟合了模型，我们可能会问：函数在新的 `x0` 值处看起来是什么样子？所以系数本身并不那么有趣。




由于拟合函数实际上是系数 `β_hat` 的线性函数，我们可以为逐点方差得到一个简单的表达式。也就是说，`x0` 处拟合函数的方差是多少？`x0` 处的拟合函数只是参数的一个线性组合。因此，通过使用拟合参数的协方差矩阵，你可以得到这个拟合值方差的一个简单表达式。我们在书中更详细地描述了这一点。






在图中，我们似乎绘制了拟合函数加减2个标准误差（我之前说成了1个）。所以得到这些逐点标准误差是相当直接的。“逐点”意味着标准误差带是逐点的，因此该带显示的是在任何给定点的标准误差。这不要与全局置信带混淆，那是另一回事。





另一个问题是，我们使用多少阶？这里我们实际上使用了四阶多项式（我之前说成了三阶）。所以这个阶数 `D` 显然是一个参数。通常我们只是选择 `D` 为一个小数字，比如2、3或4。否则，我们实际上可以通过交叉验证来选择 `D`，将其视为一个调优参数。





### 逻辑回归中的多项式





对于逻辑回归，细节基本相同。正如我在图中提到的，这就是我们建模的内容。所以这是我们的逆逻辑函数，它只是一个多项式而不是线性函数。






一个有点重要的细节是：为了获得置信区间，如果你尝试使用某种直接方法为概率获取置信区间，你可能会得到超出 [0, 1] 范围的结果。所以，你应该为拟合的对数几率获取置信区间，然后将置信带的上限和下限端点通过逆对数几率变换，这样就得到了拟合概率的置信区间。这是一个有用的技巧，请记住。





### 多变量与注意事项






好的，还有一些其他要点。我们刚刚讨论了单变量的情况。对于多个变量，你可以对每个变量分别进行。你只需在每个变量上生成这些变换，然后将它们全部堆叠在一个大矩阵中，并在所有这些新派生的变量上拟合一个大的线性模型。如果你有一个变量 `x`，你可以生成 `x1`、`x2` 直到 `x4`；你有另一个变量 `z`，你可以生成 `z1` 直到 `z4`；然后你只需将它们全部堆叠起来，构建一个大的模型矩阵并拟合你的线性模型。然后你必须解包这些部分以组合函数。稍后我们将看到，广义可加模型技术可以帮助你以无缝的方式做到这一点。





多项式回归有一些注意事项。正如我之前提到的，多项式具有众所周知的尾部行为，对于外推非常不利。这些尾部往往会摆动，你真的不会相信数据范围之外或甚至太靠近数据末端的预测。



最后，在R中拟合多项式非常简单。这是一个用于将 `x` 的多项式拟合到 `y` 的简单表达式。`poly` 函数为你生成这些变换，就这么简单。我们将在实验课中获得一些经验。


## 阶梯函数 📉










阶梯函数是拟合非线性的另一种方式，特别是在过去20年左右在流行病学和生物统计学中很流行。





具体做法是：将你的连续变量切割成离散的子范围。例如，这里我们在35岁处切割了年龄，在65岁处也切割了（实际上在50岁处也有一个切割点）。然后，想法是在每个区域中拟合一个常数模型。所以这是一个分段常数模型。






你可以在这里看到，当你拟合它们并一起绘制时，你看到第一个范围内的常数，第二个范围内的常数，第三个范围几乎看不见（它不同），然后在第四个范围。所以当它们组合在一起时，就成为一个非线性函数，即分段常数函数。





如果存在一些感兴趣的自然分割点，这通常很有用。例如，35岁以下的人的平均收入是多少？你可以直接从图上读出来。这通常适用于报纸、报告等中的总结，这也导致了它的流行。




### 实现与比较





要这样做，就像多项式一样容易。如果你考虑这里的这个函数，它是一个二元变量。你创建一个二元变量：`x` 是否小于35？如果是，你将其设为1；如果不是，你将其设为0。对于每一个分割点，都是同样的操作。所以你创建了一堆虚拟变量（0/1变量），然后只用线性模型拟合它们。





你已经可以看到这相对于多项式的优势了，对吧？这是局部的。记住，对于多项式，它是适用于整个 `x` 变量范围的单一函数。例如，如果我改变左侧的一个点，它可能会显著改变右侧的拟合。这是一个很好的观点，我之前忘了说。但对于阶梯函数，一个点只影响它所在分区的拟合，而不影响其他分区。多项式参数处处影响函数，并可能产生戏剧性的影响。




我们对逻辑回归做了同样的事情，但使用了分段常数函数，其他一切都一样，但拟合函数有点“块状”，可能被认为不那么有吸引力。




### 优势与R实现







阶梯函数易于使用，正如我所说，你创建一堆虚拟变量，然后拟合线性模型。





它也是创建易于解释的交互作用的有用方式。例如，考虑线性模型中年份和年龄的交互效应。你可以这样做：例如，为年份创建一个虚拟变量，比如切割年份小于2005，以及另一个年份大于等于2005的变量。然后，如果你将其与年龄相乘，你就创建了一个交互作用，这将为2005年前工作的人和2005年后工作的人拟合两个不同的关于年龄的线性模型。这样，从视觉上看很好。你会看到两个不同的线性函数。这是观察交互效应的一种简单方式。





在R中，创建这些虚拟变量真的很容易。创建一个指示函数与我们刚才展示的表达式基本相同。R中有一个函数 `I`，基本上就是一个指示器。`year < 25` 会变成一个逻辑值，但当包裹在 `I` 中时，它本质上是一个0/1变量。




如果你想在多个位置切割，有一个叫做 `cut` 的函数。你可以切割年龄，并给它切割点。你需要给 `cut` 两个边界点，在这个例子中是18和90（这些是年龄的范围），然后是内部的切割点。它会为你创建一个因子，一个有序因子，将变量切割到那些箱子中。





### 注意事项



现在，切割点或我们即将称之为“节点”的选择可能有点问题。对于创建非线性，有更平滑的替代方案，我们接下来会讨论。你可能只是选择了一个不幸的切割点，它根本没有显示出非线性。所以这有点艺术性。通常，如果存在你想要使用的自然切割点，分段常数函数尤其好用。
