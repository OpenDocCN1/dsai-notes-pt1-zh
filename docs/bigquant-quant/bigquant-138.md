在本节课中，我们将对支持向量机算法进行一次完整的梳理和回顾，旨在加深对该算法的理解与认识。


## 算法概述与核心思想



支持向量机，英文名为 Support Vector Machine。其中，“Support”意为支持，“Vector”意为向量，可以将其理解为数据点。

支持向量机在进行分类或回归任务时，其核心思想是**以最大的间隔将不同类别的数据分开**。这种“最大间隔”原则使得分类边界能够兼顾两侧的数据，从而获得更好的泛化效果。

在神经网络兴起之前，支持向量机在工业界和互联网领域风靡了十数年，是一个非常经典且应用广泛的算法。



## 最大间隔分类原理


那么，如何实现这种最大间隔的分类呢？


观察二维数据，中间的黑色实线（决策边界）距离红色点和蓝色点正好处于中间位置。我们寻找的分割边界（即两条虚线）刚好位于临界点。例如，p1、p2、p3点就位于分割边界上。其他蓝色点都在p3点的左侧，其他红色点都在p1、p2点的右侧。


这些位于边界之外的点特征足够明显，因此容易被区分。这类似于现实世界：特征越明显、越突出，就越容易从人群中脱颖而出。我们的目标就是让自己（或我们的模型）尽可能地远离这条决策边界，变得足够“耀眼”。


## 从几何距离到数学优化


基于上述思想，我们的问题就转化为对“距离”的数学优化。

中间决策边界到两侧虚线的距离为d，我们希望这个间隔d越大越好。为了让计算机理解并计算，我们需要将几何概念转化为数学公式。

经过一系列推导和化简，我们可以得到上侧虚线的方程为 **w^T x + b = 1**，下侧虚线的方程为 **w^T x + b = -1**。这里的推导基于二分类问题，支持向量机同样可以通过一些策略（如“一对一”或“一对多”）扩展到多分类。



最终，我们得到间隔d的表达式为 **d = 1 / ||w||**。由于我们希望d最大化，而w在分母上，这等价于希望**||w||最小化**。因此，优化目标转化为最小化 **1/2 * ||w||^2**。选择1/2系数是为了后续求导方便。



同时，作为一个分类问题，我们需要加入约束条件：对于所有样本点 **(x_i, y_i)**（其中y_i为类别标签，取+1或-1），必须满足 **y_i (w^T x_i + b) >= 1**。这个条件确保了所有样本都被正确分类且位于间隔边界之外。


## 处理约束：拉格朗日乘子法与KKT条件




现在，我们面临一个带约束的最小化问题：在 **y_i (w^T x_i + b) >= 1** 的约束下，最小化 **1/2 * ||w||^2**。


处理这类约束优化问题，需要引入**拉格朗日乘子法**。对于等式约束，拉格朗日函数写作：**L(x, λ) = f(x) + λ * h(x)**，它将有约束问题转化为无约束问题。



然而，我们的约束是不等式（>=）。这时就需要用到**KKT条件**，它是拉格朗日乘子法在不等式约束下的推广。KKT条件包含：
*   原问题的约束条件。
*   对偶可行性条件（拉格朗日乘子 λ_i >= 0）。
*   互补松弛条件（λ_i * [y_i (w^T x_i + b) - 1] = 0）。



通过引入拉格朗日乘子 α_i (α_i >= 0)，我们可以构建出支持向量机的拉格朗日函数。



## 对偶问题转换




直接求解上述拉格朗日函数的最小值问题（关于w和b）比较复杂，因为它需要在满足约束下求内层最小值。



一个巧妙的方法是将其转换为**对偶问题**。通过数学推导，原始的最小化问题可以等价地转化为一个最大化问题，其形式如下：


**max L(α) = Σ α_i - 1/2 * Σ Σ α_i α_j y_i y_j (x_i^T x_j)**
**s.t. Σ α_i y_i = 0, 且 α_i >= 0**


对偶转换的优势在于：
1.  优化变量从w和b变成了拉格朗日乘子α。
2.  目标函数中出现了样本向量之间的内积 **x_i^T x_j**，这为后续引入核函数奠定了基础。
3.  求解过程更高效，且最终模型仅依赖于那些α_i > 0的样本点，这些点就是“支持向量”。




## SMO算法求解



转换后的对偶问题是一个二次规划问题，但样本量很大时，通用求解器效率很低。



**序列最小优化算法** 是专门为求解SVM对偶问题而设计的高效算法。其核心思想是：
*   它采用一种“分而治之”的策略，每次只选择两个拉格朗日乘子α_i和α_j进行优化，固定其他所有乘子。
*   由于存在约束 **Σ α_i y_i = 0**，每次优化两个变量可以保证约束始终成立。
*   通过解析方法直接计算这两个变量的最优解，从而避免复杂的数值优化过程。
*   重复这个过程，直到所有乘子都满足KKT条件为止。



SMO算法就像一种“高效的穷举”或“有指导的猜测”，通过多次迭代快速收敛到最优解。

## 从线性到非线性：核函数




之前讨论的都是在原始特征空间中寻找线性分界超平面。对于非线性可分的数据，我们需要将数据映射到一个更高维的特征空间，使其在那个空间中线性可分。



核函数的精妙之处在于，它能够直接计算数据在高维空间映射后的内积，而无需显式地进行高维映射。常用核函数包括：
*   线性核：**K(x_i, x_j) = x_i^T x_j**
*   多项式核：**K(x_i, x_j) = (γ * x_i^T x_j + r)^d**
*   径向基函数核：**K(x_i, x_j) = exp(-γ * ||x_i - x_j||^2)**



引入核函数后，对偶问题的目标函数中的内积 **x_i^T x_j** 就替换为 **K(x_i, x_j)**，从而实现了非线性分类。



## 算法总结与回顾



本节课我们一起回顾了支持向量机的完整推导过程：



1.  **核心思想**：寻找最大间隔的分类超平面，以获得强泛化能力。
2.  **数学建模**：将最大化几何间隔问题转化为最小化 **1/2 * ||w||^2** 的优化问题，并附上分类约束。
3.  **约束处理**：利用**拉格朗日乘子法**和**KKT条件**处理不等式约束，构建出拉格朗日函数。
4.  **求解转换**：通过转换为**对偶问题**，使优化目标更清晰，并引出支持向量的概念。
5.  **高效求解**：使用**SMO算法**高效求解对偶问题中的拉格朗日乘子。
6.  **非线性扩展**：通过**核函数**技巧，将算法优雅地扩展到非线性分类场景。
