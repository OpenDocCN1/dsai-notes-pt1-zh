# Seaborn 绘图教程 P10：L10 - 绘图风格设置 🎨


在本节课中，我们将学习如何使用 Seaborn 库来设置和调整绘图风格。通过调整坐标轴、网格、字体大小和背景等元素，我们可以让图表更加美观、清晰，并适应不同的展示场景（如论文、演示文稿或海报）。


---

上一节我们介绍了 Seaborn 的基础绘图功能，本节中我们来看看如何为图表设置样式。


首先，我们可以使用 `sns.set_style()` 函数来设置坐标轴和网格的样式。该函数接受几个预设的样式名称作为参数。



以下是可用的样式选项：


*   `white`
*   `dark`
*   `whitegrid`
*   `darkgrid`
*   `ticks`


例如，要设置白色背景样式，可以使用以下代码：


```python
import seaborn as sns
sns.set_style("white")
```

设置样式后，创建的图表将应用新的背景和网格样式。不同的样式适用于不同的数据和配色方案。

---



上一节我们设置了整体样式，本节中我们来看看如何根据展示媒介调整图表的上下文，例如字体大小和线条粗细。



我们可以使用 `sns.set_context()` 函数来调整图表的上下文，使其更适合在纸张、演讲或海报上展示。



以下是可用的上下文选项：


*   `paper`：适用于笔记本或论文，元素尺寸较小。
*   `talk`：适用于演讲，元素尺寸较大，更易查看。
*   `poster`：适用于海报，元素尺寸最大。

此外，还可以通过 `font_scale` 参数单独调整字体缩放比例。例如：


```python
sns.set_context("paper", font_scale=1.4)
```



这样，图表的字体大小会按比例放大，而其他元素（如线条）保持 `paper` 上下文的默认尺寸。


---



上一节我们调整了整体上下文，本节中我们来看看如何更精细地控制图表边框（脊柱）的显示。



我们可以使用 `sns.despine()` 函数来隐藏图表中不需要的边框。

该函数可以接受参数来控制具体隐藏哪条边：



*   `left=True/False`
*   `right=True/False`
*   `top=True/False`
*   `bottom=True/False`


例如，要隐藏左侧和底部的边框，可以这样写：


```python
sns.despine(left=True, bottom=True)
```

默认情况下，设置左侧会影响右侧，设置底部会影响顶部。但你可以通过显式设置 `right` 和 `top` 参数来覆盖这一行为。

---


本节课中我们一起学习了如何设置 Seaborn 图表的风格。



我们首先介绍了如何使用 `sns.set_style()` 来改变坐标轴和网格的预设样式。



接着，我们学习了如何使用 `sns.set_context()` 来调整图表元素的大小，使其适配纸张、演讲或海报等不同场景。



最后，我们探讨了如何使用 `sns.despine()` 函数来精细控制图表边框的显示与隐藏。
